# 🌦️ Simple Weather App

A lightweight desktop weather application built with **Python** and **Tkinter**, using the **Open-Meteo API** to fetch real-time weather data.

## 🚀 Features
* Clean and simple graphical user interface (GUI) built with Tkinter[cite: 1].
* Fetches live weather information (Temperature, Rain, and Relative Humidity) for major Greek cities (Athens, Thessaloniki, Patras).
* Utilizes the free Open-Meteo REST API[cite: 1] via `openmeteo_requests`[cite: 1].

## 🛠️ Prerequisites & Installation

Make sure you have Python installed and venv, then install the required dependency for the API (OPENMETEO):
